Само FTP качване не стартира Python приложение. Хостингът трябва да поддържа Python/ASGI, Passenger, VPS или Docker.

2. База данни

Относителният път се създава спрямо root папката на проекта.

PostgreSQL базата трябва вече да съществува. Installer-ът ще създаде необходимите таблици чрез Alembic.

Връзката още не е тествана.

3. Основен owner акаунт

Това ще бъде единственият owner. След инсталацията той може да създава admin и moderator акаунти.

Минимум 12 символа. Паролата няма да бъде записана в .env - в базата се съхранява само scrypt hash.

4. Инсталиране

MMI2 ще тества базата, ще приложи migrations, ще създаде owner, ще генерира JWT secret, ще запише .env и ще заключи installer-а.

Готов за инсталация.
